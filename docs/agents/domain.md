# Domain documentation

This is a single-context repository.

Before exploring a feature, read the root `CONTEXT.md` when it exists and read ADRs under `docs/adr/` that touch the area being changed. If those files do not exist, proceed without creating them solely for setup.

Use the terminology established by `CONTEXT.md` in issue titles, specifications, tests, and implementation proposals. If a needed domain term is not defined, record that gap rather than silently introducing competing synonyms.
