What else can a terminal block become?

A small design lab for Pi's semantic output blocks. The reference direction is an elevated block with a hard offset shadow; the alternatives below explore rails, recesses, folds, outlines, stacks, tabs and conversation structure.

设计判断

当前的 elevated 是“向前凸”的 material language。下一步最值得比较的不是更多阴影层数，而是让不同 semantic block 拥有不同的空间关系：user 是入口，tool 是侧栏，error 是内嵌警示，streaming 是聚光灯。

实现约束

  • 所有样式都保持终端宽度不变，最多消耗 1-3 列。
  • 阴影从 semantic background 相对推导，不写死主题颜色。
  • 优先使用背景色和简单边缘，谨慎依赖 Unicode 几何字形。
  • 长输出默认克制，只有 active block 才值得高对比度。

This is a visual study, not a claim that every direction should ship. Open the file locally and use the filter buttons to compare the material languages in isolation.
